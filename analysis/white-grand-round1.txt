CZ White Grand, calibration round 1 (2026-11-13)
Reference: official Nord White Grand demo (nordkeyboards.com, 56 s, 256 kbps), kept in private/reference-audio/.
Base patch: history/keyscape/CZ White Grand v1.prt_key (LA Custom C7).

Method
- The reference and a live take are different music, so band levels mix register with timbre. A first pass
  with the German Concert MIDI (centroid 265 Hz against 522 Hz for the reference) read as far too bassy.
- tools/analysis/register_match.py builds a random performance with the reference's key histogram and note
  density (two seeds: white-grand-match, white-grand-match-s7). Both are rendered through each variant.
- One-parameter sweeps, then three combined rounds (13 renders). Errors are MINE - REF per octave band (dB),
  each band relative to total power.

Changes (v1 -> calibrated)
  Lo Cut   EFFRACK[0]/EFFMODULE[0]@P2           0    -> 0.45   (32 Hz rumble +9 dB)
  Hi Freq  EFFRACK[0]/EFFMODULE[0]@P5           0.14 -> 0.07   (shelf moved from 14 kHz to 7 kHz)
  Hi Boost EFFRACK[0]/EFFMODULE[0]@P3           0.26 -> 0.55   (4 kHz -7.5 dB, 8 kHz -8.9 dB)
  Imager   VOICE[0]/EFFRACK[0]/EFFMODULE[3]     off  -> on, P1 width 0.5 (side/mid 0.66 -> 0.52 average)
