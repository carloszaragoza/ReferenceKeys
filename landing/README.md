# Landing page: ReferenceKeys

Static site (HTML, CSS and vanilla JS, no build step), published with GitHub Pages by `.github/workflows/pages.yml`.

- Language: follows the browser/system language (Spanish if it starts with `es`, English otherwise). The ES/EN button overrides it.
- Theme: follows the system light/dark setting.
- Audio: `assets/audio/`, only my own recordings and renders of my own MIDI. No third-party demos.
- UI strings: `locales/en.js` and `locales/es.js` (the only place with Spanish text).
- Data: `data.js` is generated by `tools/landing/build_data.py` from real measurements (octave bands, tilt, brightness, width, balance), a spectrogram and waveform peaks.
- Fonts: Big Shoulders Display (display), Geist and Geist Mono (all OFL), self-hosted. Icons: Phosphor (MIT).
- Illustrations: no photos. Vector line drawings in `assets/art/`, generated by `tools/landing/draw_art.py` (each SVG carries its own light/dark palette).
- Gate: on the first visit of a session, "Headphones on?" asks for sound or silence while it preloads the demo. Sound unlocks Web Audio and starts the hero. Esc enters in silence.
- Hero scope: live spectrum bars plus the measured octave curve against the Roland reference, measured in the browser while the demo plays.
- Live analyzer: Web Audio AnalyserNode on the A/B player, averaged octave bands per version, compared with the Roland reference.
- Story: "Hear the lean" plays the unbalanced V2 render and a channel splitter drives the L/R meter from the real signal (running energy average).
- Social card: `assets/og.jpg`, rendered from `tools/landing/og.html` by `tools/landing/make_og.sh`. `404.html` is served by GitHub Pages for missing paths.

Local preview: `cd landing && python3 -m http.server 8765` and open http://localhost:8765

After rebuilding audio or measurements: `python3 tools/landing/build_data.py` from the project root (needs numpy and scipy).

To publish: push to `main` on github.com/carloszaragoza/ReferenceKeys, then in Settings > Pages choose "GitHub Actions" as the source.
