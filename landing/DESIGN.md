# ReferenceKeys design system

The page is a listening room: a dark stage where sound gets measured, and quiet paper pages where the numbers get explained.
Every token lives in `:root` in `styles.css`. The live sheet is `design.html` (published at `/ReferenceKeys/design.html`).

## Principles

1. **Measured, not decorated.** Every chart, number and curve on the page comes from a real measurement. Decoration that pretends to be data is not allowed.
2. **One accent, and it means something.** Vermilion is the red felt of a piano hammer. Use it for what we made (our curve, the pressed key, the hammer) and for the main action. Never for decoration.
3. **Drawn, not photographed.** Illustrations are vector line drawings generated by `tools/landing/draw_art.py`. No stock photos.
4. **Sound is opt-in.** Nothing plays until the visitor chooses it (the gate, a play button, a "Hear" button).

Three families, each with one job. All OFL, self-hosted.

| Geist 400/500/600 | `--font` | Reading: claims, leads, body, buttons |
| Geist Mono 400/500 | `--mono` | Numbers, units, axes, eyebrows, labels. Tabular figures (`.num`) |

Rules: headings tighten letter spacing; mono labels open it up. Never mix families inside one heading; emphasis uses the accent color in the same family.

## Space

4px base: `--s-1` 4, `--s-2` 8, `--s-3` 12, `--s-4` 16, `--s-5` 24, `--s-6` 32, `--s-7` 48, `--s-8` 72, `--s-9` 96.

| Token | Value | Use |
|---|---|---|
| `--section` | 72 to 128px | Vertical padding between sections |
| `--gutter` | 16 to 40px | Side padding of `.wrap` (16px on phones) |
| `--max` | 1240px | Content width |

Inside components use the 4px scale; between components use `--s-5` or more; between sections use `--section`.

## Shape and depth

- `--r` 14px for panels, charts and illustrations. `--r-sm` 10px for small tiles inside panels. `--pill` for everything you can press.
- One shadow (`--shadow`), tinted to the background, only on panels that hold data.
- Lines are 1px `--line`. Illustrations use 1.2px non-scaling strokes.

## Motion

- `--ease` (expo out) for everything. `--dur-1` .25s for UI state, `--dur-2` .5s for content changes, `--dur-3` .9s for entrances.
- Display words rise out of a mask (`.wm`). The stage drawing and the story drawing move with scroll timelines; browsers without them get the still image.
- No scroll listeners: IntersectionObserver for reveals and story steps, requestAnimationFrame only while audio plays.
- `prefers-reduced-motion: reduce` turns off entrances, drift and zoom.

## Illustration

Generated, never traced from photos: `python3 tools/landing/draw_art.py` writes `assets/art/*.svg`.

- Hairline ink strokes, occluding fills in the surface color so parts overlap like a technical drawing.
- Accent only on felt and on the thing being played: hammers, damper felt, pressed keys, the strike arc.
- Each SVG carries its palette: `stage` (always dark), or `page` / `band` / `panel` (follow the theme, matching the surface they sit on).

| File | Palette | Where |
|---|---|---|
| `piano-top.svg` | stage | Social card and this sheet. The hero draws the same geometry live on a canvas |
| `strings.svg` | page | Story opener |
| `hands.svg` | band | Live takes |
| `action.svg` | stage | Method tile |

## Components

Buttons (`.btn--accent`, `.btn--ghost`, `.btn--glass` on the stage, `.btn--lg` / `.btn--sm`), tabs, segmented control, chips, the "Hear" toggle, the live piano (3D tilt toward the cursor, keys driven by the analyser), charts (reference in ink, before in dashed faint, ours in accent with a soft gap fill). See `design.html` for every one of them rendered with the live tokens.

## Accessibility

- Text contrast AA or better in both themes; accent buttons carry dark ink.
- Every control is a real button or link with a visible focus ring (2px accent).
- The gate is a modal dialog: focus is trapped, Esc enters in silence.
- Charts have text equivalents (metrics list, live readouts in `aria-live`).
